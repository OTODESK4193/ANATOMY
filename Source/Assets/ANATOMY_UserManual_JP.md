## 1. ANATOMYとは

**ANATOMY** は、オーディオファイルを「**トランジェント（過渡成分）**」と「**トーナル（持続成分）**」に分離し、それぞれを独立したエフェクトチェーンで処理する、ハイパフォーマンスな VST3 プラグインです。

分離には **cos²クロスフェード** アルゴリズムを使用しており、`transient + tonal = original` が数学的に保証されます。エネルギー損失やオーバーラップによるアーティファクトは一切発生しません。

### 基本ワークフロー

1. **WAVファイルをドラッグ＆ドロップ**でプラグインに読み込む
2. 分離パラメータ、ピッチ、ゲインで各成分を整形
3. 各レーンに独立したエフェクトチェーンで加工
4. **EXPORT**でWAVに書き出し→サンプラーに読み込んで使用

> **重要: ANATOMY はサウンドデザインツールです。** リアルタイム挿入プラグインとしての常時使用は想定していません。音色を作り込んだら **EXPORT** でWAVに書き出し、Ableton Simpler / Sampler、Kontakt 等の高機能サンプラーに読み込んで使用してください。

### 3つの信号レーン

| レーン | 内容 | 用途 |
|---|---|---|
| **TRANSIENT** | アタック・クリック成分 | パンチ、スナップの強調・整形 |
| **TONAL** | サステイン・調波成分 | ボディ、余韻のトーンシェイピング |
| **FULL MIX** | 分離後の再合成信号（2色比率表示） | 並列処理、最終段のリミッティング |

## 2. システム要件とインストール

### システム要件

| 項目 | 要件 |
|---|---|
| **OS** | Windows 10 / 11（64-bit） |
| **フォーマット** | VST3 |
| **CPU** | AVX2 対応必須（Intel Haswell 2013年以降 / AMD Ryzen 2017年以降） |
| **RAM** | 256 MB 以上 |
| **ディスク** | 50 MB 以上 |
| **推奨 DAW** | Ableton Live 11 / 12 |

### インストール方法

1. [Releases ページ](https://github.com/OTODESK4193/ANATOMY/releases/latest) から最新の `ANATOMY.vst3` をダウンロード
2. `.vst3` フォルダを `C:\Program Files\Common Files\VST3\` へコピー
3. Ableton Live → 環境設定 → プラグイン → 再スキャン
4. ブラウザから **ANATOMY** をトラックへドラッグ

### 3.1 トップバー（出力モード選択）

| ボタン | 機能 |
|---|---|
| **Full Mix** | 3レーンをミックスした最終出力をモニタリング |
| **Transient Solo** | TRANSIENTレーンのみをモニタリング |
| **Tonal Solo** | TONALレーンのみをモニタリング |
| **BEFORE** | 処理前の原信号とA/B比較（エフェクト・ゲインバイパス） |

### 3.2 コアコントロール（ノブエリア）

トップバーの直下に配置された回転ノブ群です。左半分がTransient関連、右半分がTonal関連のパラメータです。

### 3.3 波形ディスプレイ

3段の波形表示エリアです。各波形の右下に **+/-ズームボタン** があります。

- **FULL MIX（上段）** — 2色エネルギー比率表示（シアン=トランジェント、マゼンタ=トーナル）。右側にTONAL OFFSETスライダーとEXPORTボタン
- **TRANSIENT（中段）** — シアンの波形。右側にBrowse/ResetとEXPORTボタン
- **TONAL（下段）** — マゼンタの波形。右側にBrowse/ResetとEXPORTボタン

### 3.4 エフェクトラック（右側パネル）

TRANSIENT / TONAL / FULL MIX 各レーンに6種のエフェクトボタン（SATU / CRUSH / NOISE / OTT / GLUE / LIMIT）とチップバーが表示されます。

### 3.5 パラメータードック（最下部）

選択中エフェクトのパラメーターノブが表示されます。

## 4. クイックスタート

### Step 1 — オーディオを読み込む

WAVファイルをANATOMYのプラグインウィンドウにドラッグ＆ドロップします。波形が表示され、自動的にTransient/Tonalに分離されます。

### Step 2 — 分離を確認する

1. **Transient Solo** ボタンでトランジェントだけを試聴
2. **Tonal Solo** ボタンでトーナルだけを試聴
3. **BEFORE** ボタンで処理前の原信号と比較

### Step 3 — 分離パラメータを調整する

- **CLICK HOLD** — トランジェントとして保持する区間の長さ（ms）
- **SUSTAIN FADE-IN** — トランジェントからトーナルへのcos²クロスフェード時間（ms）

### Step 4 — エフェクトを追加する

1. エフェクトラックのボタンをクリックしてエフェクトを追加
2. チップバーのチップをクリックして選択→パラメータードックで調整
3. チップをドラッグ＆ドロップで処理順序を変更

### Step 5 — エクスポートする

**EXPORT** ボタンを押して録音開始→DAWで再生→WAVをDAWタイムラインへドラッグ。

## 5. コアコントロール詳細

### 5.1 トランジェント関連

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **CLICK HOLD (ms)** | 0.0 – 50.0 | 10.0 | トランジェント保持区間の長さ。この期間は`transient = input`、`tonal = 0` |
| **TRANSIENT PITCH (st)** | -12 – +12 | 0.0 | トランジェントのピッチシフト量（半音単位） |
| **TRANSIENT GAIN (dB)** | -60 – +6 | 0.0 | トランジェントレーンの出力ゲイン |

### 5.2 トーナル関連

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **SUSTAIN FADE-IN (ms)** | 1.0 – 100.0 | 5.0 | cos²クロスフェードの持続時間。トランジェント→トーナルへの滑らかな移行 |
| **SUSTAIN RELEASE (ms)** | 10 – 5000 | 500 | トーナル成分のリリース（余韻の長さ） |
| **TONAL PITCH (st)** | -12 – +12 | 0.0 | トーナルのピッチシフト量（半音単位） |
| **TONAL GAIN (dB)** | -60 – +6 | 0.0 | トーナルレーンの出力ゲイン |

### 5.3 Tonal Offset

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **TONAL OFFSET (ms)** | -500 – +500 | 0.0 | トーナルの再生開始位置をトランジェントに対して前後にずらす |

FULL MIX波形エリアの右側に横スライダーとして配置されています。±50ms付近の調整がしやすいよう、対称スキューが適用されています。

- **負の値（左）**: トーナルが早く再生開始（Transient Pitchを上げて短くなったときの隙間を埋める用途）
- **正の値（右）**: トーナルの再生を遅延

この設定はFullMix / Transient / Tonalの個別エクスポート時にも反映されます。

## 6. 波形ディスプレイとズーム

### 6.1 2色エネルギー比率表示（FULL MIXのみ）

FULL MIX波形はトランジェントとトーナルのエネルギー比率を2色で表示します。シアン（水色）がトランジェント成分、マゼンタがトーナル成分の寄与を視覚的に示します。

### 6.2 ズーム機能

全3レーンの波形右下に **+** / **-** ボタンがあります。

- **+** をクリック: 2倍にズームイン（左端起点で拡大）
- **-** をクリック: 半分にズームアウト
- ズーム範囲: x1 ～ x32
- 現在の倍率がボタン左に表示されます

トランジェントが非常に短い場合、ズームインすることで波形の細部を確認しながらパラメータを調整できます。

### 6.3 START/END トリミング

各波形上で黄色（START）と赤色（END）のマーカーをドラッグして、再生区間をトリミングできます。

### 6.4 DRAG EXPORT

各波形の右上にある **DRAG EXPORT** ボタンから、波形データをDAWのタイムラインへ直接ドラッグ＆ドロップできます。

## 7. カスタムサンプル差し替え

TRANSIENT / TONAL の各レーンには **Browse** と **Reset** ボタンがあります。

- **Browse**: 任意のWAVファイルを読み込み、分離されたTransient/Tonal成分を独自のサンプルで差し替えます
- **Reset**: カスタムサンプルをクリアし、元のcos²分離結果に戻します

カスタムサンプルを読み込んだ状態でもEXPORTは正常に動作し、差し替えた音声が書き出されます。

## 8. エフェクトの操作方法

### 8.1 エフェクトの追加

エフェクトラックの該当レーンにある 6 つのボタン（**SATU / CRUSH / NOISE / OTT / GLUE / LIMIT**）をクリックします。ボタンが点灯し、チップバーにエフェクトチップが追加されます。

### 8.2 エフェクトの選択（パラメーター表示）

チップバー内のチップをクリックすると選択状態（ハイライト）になり、パラメータードックにパラメーターが表示されます。

### 8.3 エフェクトの順序変更（ドラッグ＆ドロップ）

チップバー内でチップを上下にドラッグして処理順序を変更できます。同レーン内のみ移動可能です。

### 8.4 エフェクトの削除

チップを**右クリック**してコンテキストメニューから **Remove** / **Move Up** / **Move Down** を選択します。

### 8.5 処理順序

チップバーの上位のエフェクトから順に処理されます。全6種類を同時に使用できます。

## 10. ステムエクスポート

### EXPORTボタン方式

1. 各レーンの **EXPORT** ボタンをクリック（録音モード開始、ボタンがオレンジに点灯）
2. DAWでオーディオを再生
3. 録音完了後、ボタンが緑に変化（DRAG OK!）
4. ボタンからWAVファイルをDAWタイムラインへドラッグ＆ドロップ

### DRAG EXPORT方式

各波形の右上にある **DRAG EXPORT** ボタンから、オフライン生成された波形をDAWへ直接ドラッグできます。

### 注意事項

- エクスポートされるのはエフェクト適用済みの信号です
- ファイル形式: 32-bit float WAV
- Tonal Offsetの設定はFullMix / Transient / Tonalの個別エクスポートすべてに反映されます
- 録音中にDAWのテンポや再生レートを変更しないでください

## 11. DAWプロジェクト保存・復元

ANATOMYは以下のデータをDAWプロジェクトと一緒に自動保存します：

- 読み込んだオーディオデータ（WAVの内容）
- ファイルのサンプルレート
- カスタム差し替えサンプル（TransientおよびTonal）
- 全パラメータ値（Tonal Offset含む）
- START/ENDトリミング位置

プロジェクトを開き直すと、バッファが復元されバックグラウンドでcos²分離が自動再実行されます。音声ファイルの読み込み直しは不要です。

## 12. テクニックとワークフロー

### 12.1 Transient Pitchを上げたときの隙間対策

Transient Pitchを上げるとトランジェントの再生速度が速くなり、波形が短くなります。Full MixでTransientとTonalの間に隙間が生じた場合、**TONAL OFFSET** スライダーを負の方向（左）に動かしてトーナルの再生開始位置を前にずらし、隙間を埋めてください。

### 12.2 キックのアタック強調

1. CLICK HOLD を 5〜15ms に設定
2. SUSTAIN FADE-IN を短め（2〜5ms）に設定してシャープな分離
3. TRANSIENTレーンに SATU（DRIVE 3.0）を追加
4. TRANSIENT GAIN を +3〜6dB

### 12.3 スネアのボディ加工

1. TONALレーンに OTT を追加、DEPTH 0.3〜0.5
2. GLUEで余韻を整える
3. SUSTAIN RELEASE を調整して必要な余韻の長さに

### 12.4 カスタムサンプルの差し替えによるレイヤリング

1. TRANSIENTレーンの **Browse** で別のアタックサンプルを読み込む
2. Transient PitchやGainで馴染ませる
3. オリジナルのTonalと組み合わせた新しいサウンドをEXPORT

## 13. トラブルシューティング

### 音が出ない

- WAVファイルが正しく読み込まれているか確認（波形が表示されるか）
- Gain が大きく下がっていないか確認
- BEFORE ボタンが意図せずアクティブになっていないか確認

### プラグインがDAWに表示されない

- `.vst3` が `C:\Program Files\Common Files\VST3\` にあるか確認
- DAWでプラグイン再スキャンを実行
- 64-bit版のDAWを使用しているか確認

### CPU負荷が高い

- DAWのバッファサイズを256〜512サンプルに増やす
- 使用していないエフェクトをチェーンから削除

### プロジェクトを開き直したらサンプルが消えた

- v1.0.0に更新されているか確認してください
- プロジェクトを保存し直してから再度開いてみてください

### OTTで爆音が発生する

- v1.0.0で修正済みです。最新版をお使いください

## 14. 技術仕様

### 分離アルゴリズム

cos²クロスフェード分離（時間領域処理）:
- **Hold区間**（Click Hold ms）: `transient = input`, `tonal = 0`
- **Fade区間**（Sustain Fade-In ms）: `transient = input × cos²(θ)`, `tonal = input × sin²(θ)`
- **Post-fade区間**: `transient = 0`, `tonal = input`

数学的に `transient + tonal = input` が常に保証されます。

### 信号処理

| 項目 | 仕様 |
|---|---|
| サンプル精度 | 32-bit float |
| チャンネル数 | ステレオ（2ch in / 2ch out） |
| レイテンシー | 0 sample |
| 対応サンプルレート | 44100 / 48000 / 88200 / 96000 Hz |
| フィルター構造 | ZDF / TPT（ゼロ遅延フィードバック） |
| パラメーター平滑化 | SmoothedValue によるジッパーノイズ除去 |

### リアルタイム安全性

- オーディオスレッド内での動的メモリ確保なし
- `std::atomic` およびロックフリーパターンによるスレッド間通信
- `ScopedNoDenormals` によるデノーマルCPUスパイク防止
- Ableton Live固有のサンプルレート変更バグに対する自己防衛コード
