## 1. ANATOMYとは

**ANATOMY** は、リアルタイムで音声を「**トランジェント（過渡成分）**」と「**トーナル（持続成分）**」に分離し、それぞれを独立したエフェクトチェーンで処理する、ハイパフォーマンスな VST3 プラグインです。

従来のコンプレッサーやサチュレーターは、サウンド全体に作用します。ANATOMY では、ドラムのアタック（トランジェント）とボディ（トーナル）を別々に加工することができます。例えば、アタックにサチュレーションをかけつつ、ボディには OTT マルチバンドコンプを適用する、といった処理が可能です。

> ⚠️ **重要: ANATOMY はサウンドデザインツールです。** リアルタイム挿入プラグインとしての常時使用は想定していません。音色を作り込んだら **EXPORT** 機能でWAVファイルに書き出し、Ableton Simpler / Sampler、Native Instruments Kontakt などの**高機能サンプラーに読み込んで使用**することを強く推奨します。

### 3つの信号レーン

| レーン | 内容 | 用途 |
|---|---|---|
| **TRANSIENT** | アタック・クリック成分 | パンチ、スナップの強調・整形 |
| **TONAL** | サステイン・調波成分 | ボディ、余韻のトーンシェイピング |
| **FULL MIX** | 未分離の原信号 | 並列処理、最終段のリミッティング |

各レーンに最大 6 種類のエフェクトを任意の順序で挿入でき、仕上がったステムを WAV として書き出してそのままDAWのタイムラインへドラッグ&ドロップできます。

## 2. システム要件とインストール

### システム要件

| 項目 | 要件 |
|---|---|
| **OS** | Windows 10 / 11（64-bit） |
| **フォーマット** | VST3 |
| **CPU** | AVX2 対応必須（Intel Haswell 2013年以降 / AMD Ryzen 2017年以降） |
| **RAM** | 256 MB 以上 |
| **ディスク** | 50 MB 以上 |
| **推奨 DAW** | Ableton Live 11 / 12 |

> ⚠️ **注意:** AVX2 非対応の CPU では動作しません。CPU の型番で対応状況を確認してください。

### インストール方法

1. [Releases ページ](https://github.com/OTODESK4193/ANATOMY/releases/latest) から最新の `ANATOMY.vst3` をダウンロードします。
2. ダウンロードした `.vst3` フォルダを以下のパスへコピーします：
   ```
   C:\Program Files\Common Files\VST3\
   ```
3. Ableton Live を起動し、**環境設定 → プラグイン → VST3 フォルダ** を確認後、**再スキャン** を実行します。
4. Live の「ブラウザ → プラグイン」から **ANATOMY** を検索してトラックへドラッグします。

## 3. インターフェース概要

ANATOMY のウィンドウは大きく 4 つのセクションで構成されています。

```
┌──────────────────────────────────────────────────────┐
│ [出力モード選択]   [BEFORE]              [グローバル] │  ← トップバー
├────────────────┬─────────────────────────────────────┤
│                │ FULL MIX WAVEFORM                   │  ← 波形ディスプレイ
│  コア           ├─────────────────────────────────────┤
│  コントロール   │ TRANSIENT WAVEFORM                  │
│                ├─────────────────────────────────────┤
│                │ TONAL WAVEFORM                      │
├────────────────┴──────────────┬──────────────────────┤
│ パラメータードック             │ エフェクトラック       │  ← 操作エリア
└───────────────────────────────┴──────────────────────┘
```

### 3.1 トップバー

| コントロール | 機能 |
|---|---|
| **FULL MIX** | 3レーンをミックスした最終出力をモニタリング |
| **TRANS SOLO** | TRANSIENTレーンのみをモニタリング |
| **TONAL SOLO** | TONALレーンのみをモニタリング |
| **BEFORE** | 処理前の原信号と処理後をA/B比較 |

### 3.2 コアコントロール

プラグインウィンドウ左側にある主要パラメーターエリアです。詳細は [セクション 5](#5-コアコントロール詳細) を参照してください。

### 3.3 波形ディスプレイ

画面中央に 3 つの波形がリアルタイムで表示されます：

- **FULL MIX（上段）** — 入力または出力のフルミックス波形
- **TRANSIENT（中段）** — 分離されたトランジェント成分の波形
- **TONAL（下段）** — 分離されたトーナル成分の波形

### 3.4 エフェクトラック（右側）

各レーン（TRANSIENT / TONAL / FULL MIX）について、6種類のエフェクトボタンと **チップバー**（有効エフェクトの順序リスト）が表示されます。詳細は [セクション 6](#6-エフェクトの操作方法) を参照してください。

### 3.5 パラメータードック（下部）

エフェクトを選択すると、そのパラメーターノブとスライダーがここに表示されます。ひとつのエフェクトを選択した状態で、すべてのパラメーターをリアルタイムで調整できます。

## 4. クイックスタート

以下の手順で 5 分以内に ANATOMY の基本を習得できます。

### Step 1 — プラグインを挿入する

Ableton Live のドラムトラック（またはバスチャンネル）に ANATOMY を Audio Effect として追加します。

### Step 2 — 分離を確認する

1. オーディオを再生します。
2. 波形ディスプレイで TRANSIENT と TONAL の分離状況を確認します。
3. **TRANS SOLO** ボタンでトランジェントだけを試聴します。
4. **TONAL SOLO** ボタンでトーナルだけを試聴します。

### Step 3 — エフェクトを追加する

1. エフェクトラックの **TRANSIENT レーン** にある **SATU**（サチュレーション）ボタンをクリックします。
   - ボタンが点灯し、チップバーに「SATU」チップが追加されます。
2. チップをクリックして選択します（チップが青くハイライトされます）。
3. パラメータードックに ADAA Saturation のパラメーターが表示されます。
4. **DRIVE** ノブを上げてサチュレーションを調整します。

### Step 4 — エフェクトの順序を変える

チップバー内のチップをドラッグ&ドロップして処理順序を変更できます。
例: `SATU → OTT` を `OTT → SATU` に変更する場合、OTTチップをSATUチップの上へドラッグします。

### Step 5 — ステムをエクスポートする

1. **EXPORT** ボタンを押して記録を開始します。
2. DAW で数小節再生します。
3. 録音が完了したら、EXPORTボタンから WAV ファイルをDAWのタイムラインへドラッグします。

## 5. コアコントロール詳細

エフェクトを適用する前の、レーンごとの基本的なシェイピングパラメーターです。

### 5.1 トランジェント関連

| パラメーター | 範囲 | 説明 |
|---|---|---|
| **Click Length** | 0.0 – 1.0 | トランジェント抽出ウィンドウの長さ。値を上げるほど長い「アタック領域」をトランジェントとして切り出す |
| **Click Curve** | 0.0 – 1.0 | トランジェントエンベロープの形状。0でシャープなスパイク、1でなめらかなカーブ |
| **Transient Pitch** | -24 – +24 半音 | TRANSIENTレーン出力のピッチシフト量 |
| **Transient Gain** | -24 – +24 dB | TRANSIENTレーンの出力ゲイン |

### 5.2 トーナル関連

| パラメーター | 範囲 | 説明 |
|---|---|---|
| **Sustain Release** | 0.0 – 1.0 | トーナル成分のディケイ尾部の長さ。値を上げると長い余韻を保持する |
| **Tonal Pitch** | -24 – +24 半音 | TONALレーン出力のピッチシフト量 |
| **Tonal Gain** | -24 – +24 dB | TONALレーンの出力ゲイン |

### 5.3 活用例

**キックドラムのアタックを強調したい場合:**
- Click Length を 0.3 程度に設定し、アタック部分のみを切り出す
- Click Curve を 0 寄りにしてシャープなトランジェントを作る
- Transient Gain を +3〜6 dB 上げてアタックを前に出す

**スネアのボディだけをトーンシェイピングしたい場合:**
- Sustain Release を 0.4〜0.6 に設定して余韻を適度に保持
- TONALレーンに Glue Compressor を挿入し、ボディを整える

## 6. エフェクトの操作方法

### 6.1 エフェクトの追加

1. エフェクトラックの該当レーン（TRANSIENT / TONAL / FULL MIX）にある 6 つのボタン（**SATU / CRUSH / NOISE / OTT / GLUE / LIMIT**）のいずれかをクリックします。
2. ボタンが点灯し、チップバーにエフェクトチップが追加されます。

> **注意:** ボタンを再度クリックしても OFF にはなりません。チップバーで削除操作を行ってください（下記参照）。

### 6.2 エフェクトの選択（パラメーター表示）

チップバー内のチップをクリックすると、そのエフェクトが選択状態（青くハイライト）になり、パラメータードックにパラメーターが表示されます。

### 6.3 エフェクトの順序変更（ドラッグ&ドロップ）

チップバー内でチップを上下にドラッグすることで、処理チェーンの順序をリアルタイムに変更できます。

- **ドラッグ中:** ドロップ先を示すインジケーターラインが表示されます。
- **同レーン内のみ:** 異なるレーン間のドラッグ&ドロップはできません。

### 6.4 エフェクトの削除

チップバー内のチップを**右クリック**するとコンテキストメニューが表示されます：

- **Remove** — チェーンからエフェクトを削除
- **Move Up** — 処理順序を1つ上へ
- **Move Down** — 処理順序を1つ下へ

### 6.5 複数エフェクトの組み合わせ

各レーンに最大 6 種類すべてのエフェクトを同時に使用できます。処理チェーンは上から下の順に適用されます（チップバーの上位が最初に処理される）。

**例: ドラムトランジェントの典型的なチェーン**
```
SATU → OTT → LIMIT
```
① サチュレーションでアタックを歪ませ
② OTT でダイナミクスを整え
③ リミッターで出力をクリップから保護

## 7. エフェクトリファレンス

### 7.1 🟣 ADAA サチュレーション（SATU）

Anti-Derivative Anti-Aliased（ADAA）技術を使った高品質なソフトサチュレーションです。通常のウェーブシェイパーとは異なり、エイリアシングを数学的に排除しているため、高音域が濁りにくく、クリアな倍音が得られます。

**パラメーター:**

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **DRIVE** | 1.0 – 16.0 | 2.0 | サチュレーション量。値を上げるほど強く歪む |
| **ASYMMETRY** | 0.0 – 1.0 | 0.0 | 波形の非対称性。上げると偶数次倍音（2次、4次）が増加し、温かみのある歪みに |
| **OUT TRIM** | -12 – +12 dB | 0 dB | サチュレーション後の出力レベル調整 |
| **PRE HPF** | 20 – 2000 Hz | 20 Hz | サチュレーション前のハイパスフィルター。値を上げると低音域を歪ませずに保護できる |
| **DRY/WET** | 0.0 – 1.0 | 1.0 | 原音との並列ブレンド。0.5 で並列サチュレーション |

**活用のコツ:**
- ドラムのアタックに軽くかけるなら DRIVE 2〜4、ASYMMETRY 0.2〜0.4
- PRE HPF を 200 Hz 程度に上げると、キックの低域に影響させずにアタックのみを歪ませられる

---

### 7.2 🟣 ビットクラッシャー（CRUSH）

ビット深度削減とサンプルレートデシメーションによる Lo-Fi エフェクトです。

**パラメーター:**

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **BITS** | 2 – 24 bit | 8 | ビット深度。値を下げるほど粗いデジタルノイズが発生する（8bit = ゲームボーイサウンド） |
| **DOWNSAMPLE** | 1 – 32× | 4 | サンプルレート間引き倍率。値を上げるほどサンプルレートが低下し、折り返しノイズ（エイリアシング）が発生する |
| **JITTER** | 0.0 – 1.0 | 0.0 | サンプルタイミングのランダムゆらぎ。ヴィンテージ機器特有の不安定感を再現 |
| **DRY/WET** | 0.0 – 1.0 | 1.0 | 原音との並列ブレンド |

**活用のコツ:**
- TRANSIENT レーンに低めの BITS（6〜10）をかけると、クラシックなドラムマシン風のアタックになる
- DOWNSAMPLE を 2〜4 に抑えつつ DRY/WET を 0.3 程度にすると、ナチュラルなデジタル質感

---

### 7.3 🟣 ノイズジェネレーター（NOISE）

トリガー型のノイズバーストエフェクトです。入力信号のトランジェントを検知してノイズを発生させ、スネアワイヤーのザラつき感やルームアンビエンスを付加できます。

**パラメーター:**

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **DECAY ms** | 1 – 1000 ms | 100 ms | ノイズバーストのディケイ時間 |
| **GAIN dB** | -60 – 0 dB | 0 dB | ノイズの出力レベル |
| **ATTACK ms** | 0 – 50 ms | 0 ms | ノイズのアタック時間 |
| **BP FREQ** | 0 – 4000 Hz | 0 Hz | バンドパスフィルターの中心周波数（0 = フィルターなし） |
| **TYPE** | WHITE / PINK / BROWN / BLUE | WHITE | ノイズのスペクトル特性 |
| **DRY/WET** | 0.0 – 1.0 | 1.0 | 原音との並列ブレンド |

**ノイズタイプの違い:**

| タイプ | 特性 | 用途 |
|---|---|---|
| **WHITE** | 全帯域フラット | 明るいシャリ感 |
| **PINK** | 高域が -3 dB/oct | 自然なルーム感 |
| **BROWN** | 高域が -6 dB/oct | 低い、ウォームな質感 |
| **BLUE** | 高域が +3 dB/oct | 超ブライト、エアー感 |

---

### 7.4 🟣 OTT マルチバンドコンプ（OTT）

3バンドの上方／下方コンプレッションを組み合わせた、いわゆる「OTT」スタイルのダイナミクスプロセッサーです。小さい音を持ち上げ（上方圧縮）、大きい音を抑える（下方圧縮）ことで、密度の高い、グルー感のあるサウンドが得られます。

#### メインパラメーター

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **TIME** | 0.1 – 10.0 | 1.0 | アタック/リリースの時定数（値が小さいほど速い） |
| **LO/MI XO** | 40 – 1000 Hz | 200 Hz | Low/Mid バンドのクロスオーバー周波数 |
| **MI/HI XO** | 1000 – 15000 Hz | 2500 Hz | Mid/High バンドのクロスオーバー周波数 |
| **GATE dB** | -70 – -20 dB | -45 dB | ノイズゲートフロア。これ以下の音はコンプをかけない |
| **DEPTH** | 0.0 – 1.0 | 1.0 | 全体のコンプレッション量（ドライウェット） |

#### **BANDSボタン**でバンド別パラメーターを表示

OTT のパラメータードック右上にある **BANDS** ボタンをクリックすると、3バンドそれぞれの詳細パラメーターが表示されます。

#### バンド別パラメーター（LOW / MID / HIGH）

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **UP** | 0.0 – 1.0 | 1.0 | 上方圧縮量（小さい音を持ち上げる） |
| **DOWN** | 0.0 – 1.0 | 1.0 | 下方圧縮量（大きい音を抑える） |
| **GAIN dB** | -24 – +24 dB | 0 dB | バンドの出力ゲイントリム |

**活用のコツ:**
- TRANSIENT レーンで使うと、各帯域のアタック感が均一化されてパンチのあるドラムになる
- DEPTH を 0.3〜0.5 程度に抑えて、原音感を残しながら使うのがおすすめ

---

### 7.5 🟣 グルーコンプレッサー（GLUE）

フィードフォワード RMS バスコンプレッサーです。複数のエレメントを「グルー」でまとめるように自然にまとめ上げる、バス・サミングコンプのような働きをします。

**パラメーター:**

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **THR dBFS** | -40 – 0 dB | -18 dB | コンプレッションのスレッショルド |
| **RATIO** | 1.0 – 20.0 | 2.0 | コンプレッション比率 |
| **ATK ms** | 1 – 100 ms | 30 ms | アタックタイム（短いほどトランジェントを潰す） |
| **REL ms** | 10 – 1000 ms | 200 ms | リリースタイム |
| **MAKEUP dB** | -12 – +12 dB | 0 dB | コンプ後のメイクアップゲイン |
| **DEPTH** | 0.0 – 1.0 | 1.0 | 並列ブレンド（ニューヨークコンプレッション） |

**活用のコツ:**
- FULL MIX レーンに挿入して、最終段の「まとまり感」を出すのに最適
- ATK を 30〜50 ms に設定してトランジェントを通過させると、パンチを残しながら整えられる
- DEPTH を 0.5〜0.7 にした並列コンプで、原音のダイナミクスを維持

---

### 7.6 🟣 リミッター（LIMIT）

ピーク検出型のブリックウォールリミッターです。チェーン内の最終段での音量クリッピング保護に使います。

**パラメーター:**

| パラメーター | 範囲 | デフォルト | 説明 |
|---|---|---|---|
| **CEILING dB** | -24 – 0 dB | -0.1 dB | 出力の上限（これを超えた信号は完全にカット） |
| **DRY/WET** | 0.0 – 1.0 | 1.0 | 並列ブレンド |

**活用のコツ:**
- CEILING を -1.0 dB 程度に設定しておくと、デジタルクリッピングを安全に防止できる
- DRY/WET を 0.7〜0.9 程度にして、トランスペアレントなリミッティングが可能

## 8. ステムエクスポート

ANATOMY は各レーンの出力を WAV ファイルとしてリアルタイム録音し、DAW のタイムラインへ直接ドラッグ&ドロップできます。

### エクスポートの手順

1. エクスポートしたいレーンの **EXPORT** ボタンをクリックします。
   - 録音モードが有効になり、ボタンが点灯します。
2. Ableton Live でオーディオを再生します（録音したいクリップや範囲を再生してください）。
3. 再生が終わったら、もしくは録音したい長さ分が経過したら再生を止めます。
4. EXPORT ボタンをもう一度クリック（またはボタンからWAVをドラッグ）して、ファイルを DAW のタイムラインにドラッグ&ドロップします。

### 注意事項

- ステムの録音は処理後の信号です（エフェクト適用済み）。
- エクスポートファイルは 32-bit float WAV 形式です。
- 録音中に Ableton Live のテンポや再生レートを変更しないでください。

## 9. テクニックとワークフロー

> **基本ワークフロー:** ANATOMY でサウンドを作り込む → **EXPORT** でWAVに書き出す → 高機能サンプラーに読み込む。これが推奨される使い方です。リアルタイム挿入での常時使用は推奨しません。

### 9.1 スネアのサチュレーション + ノイズ追加

1. TRANSIENT レーンに `SATU`（DRIVE 4.0、ASYMMETRY 0.3）
2. 同じ TRANSIENT レーンに `NOISE`（TYPE: PINK、DECAY 80ms、BP FREQ 3000 Hz）
3. チップバーで `SATU → NOISE` の順にする（先に歪ませてからノイズを重ねる）

### 9.2 キックのローエンド強調

1. TONAL レーンに `OTT`（BANDS で LOW バンドの UP を上げる）
2. Transient Pitch を -2〜-4 半音に調整してアタックを少し低く
3. TRANSIENT Gain を +3 dB にしてアタックを強調

### 9.3 パラレルコンプレッション（ニューヨークスタイル）

1. FULL MIX レーンに `GLUE`（RATIO 4:1、ATK 10ms、MAKEUP +6dB）
2. DEPTH を 0.4 に設定（60% ドライ / 40% コンプ信号のブレンド）
3. これだけで強烈なパンチを持ちながら原音のダイナミクスを保持

### 9.4 BEFORE ボタンを使った A/B 比較

作業中に迷ったら **BEFORE** ボタンを押して原音と比較してください。「処理をかけすぎた」と感じたら、各エフェクトの DRY/WET を下げて自然な仕上がりに近づけましょう。

## 10. トラブルシューティング

### 音が出ない

- Ableton Live の Audio Effect として正しく挿入されているか確認
- TRANSIENT / TONAL / FULL MIX の Gain が 0 dB から大きく下がっていないか確認
- BEFORE ボタンがアクティブになっている場合は一度クリックして解除

### プラグインが Ableton に表示されない

- VST3 ファイルが `C:\Program Files\Common Files\VST3\` に正しくコピーされているか確認
- Ableton Live の設定 → プラグイン → VST3 フォルダを確認し、「再スキャン」を実行
- 64-bit 版の Ableton Live を使用しているか確認（32-bit 版は非対応）

### CPU負荷が高い

- Ableton Live のバッファサイズを 256〜512 サンプルに増やす
- 使用していないエフェクトをチェーンから削除する
- FULL MIX レーンのエフェクトを減らすか無効にする

### エフェクトパラメーターが表示されない

- チップバーのチップをクリックしてエフェクトを選択状態にする（青くハイライトされる）
- チップバーに何もチップがない場合は、エフェクトボタンをクリックしてチェーンに追加する

### OTT の BANDS ボタンが表示されない

- パラメータードックの幅を広げてみてください
- OTT エフェクトが選択（ハイライト）されているか確認してください

### ステムエクスポートのWAVが空になる

- EXPORT ボタンを押した後、Ableton Live で少なくとも数小節以上再生してください
- 録音中（ボタン点灯中）に再生していることを確認してください

## 11. 技術仕様

### 信号処理

| 項目 | 仕様 |
|---|---|
| サンプル精度 | 32-bit float |
| チャンネル数 | ステレオ（2ch in / 2ch out） |
| レイテンシー | 0 sample（ゼロレイテンシー） |
| 対応サンプルレート | 44100 / 48000 / 88200 / 96000 Hz |
| フィルター構造 | ZDF / TPT（ゼロ遅延フィードバック） |
| パラメーター平滑化 | SmoothedValue によるジッパーノイズ除去 |

### リアルタイム安全性

ANATOMY は以下の「リアルタイムセーフ」設計を採用しています：

- **オーディオスレッド内での動的メモリ確保なし** — すべてのバッファは起動時に事前確保
- **ロックフリースレッド間通信** — UI↔オーディオ間は SPSC キューで通信
- **デノーマル対策** — `ScopedNoDenormals` による CPU スパイク防止
- **Ableton Live 固有バグ対策** — サンプルレート変更時の自己防衛コード実装
